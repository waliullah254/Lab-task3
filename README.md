Lab 3: Uninformed Search Algorithms

Introduction

This project covers BFS, DFS, Depth-Limited Search (DLS), Iterative Deepening DFS (IDDFS), and Uniform Cost Search (UCS).

Files

- "lab3_bfs_dfs.py" – BFS and DFS implementation.
- "lab3_bfs_dfs_output.txt" – BFS and DFS output.
- "lab3_depth_search.py" – DLS and IDDFS implementation.
- "lab3_depth_search_output.txt" – DLS and IDDFS output.
- "lab3_ucs.py" – UCS implementation.
- "lab3_ucs_output.txt" – UCS output.
- "Lab3_Report.docx" – Lab report.

How to Run

Open the project folder in VS Code and run:

python lab3_bfs_dfs.py
python lab3_depth_search.py
python lab3_ucs.py

Requirements

- Python 3
- No external packages are required.

Conclusion

The lab demonstrates how uninformed search algorithms explore a graph and how BFS and UCS can produce different paths depending on the search criteria.
